# Improving-Deep-Neural-Networks-Hyperparameter-Tuning-Regularization-and-Optimization

You've always used Gradient Descent to update the parameters and minimize the cost. In this project, I am applying some more advanced optimization methods that can speed up learning and perhaps even get you to a better final value for the cost function. Having a good optimization algorithm can be the difference between waiting days vs. just a few hours to get a good result.

In this project, I am presenting how to:

Apply optimization methods such as (Stochastic) Gradient Descent, Momentum, RMSProp and Adam
Use random minibatches to accelerate convergence and improve optimization
